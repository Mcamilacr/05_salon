# Salón de Belleza - SPA

Proyecto de Programación Web - UIS 2026-II (Fase I). React + Vite + React-Bootstrap.

**Versión publicada:** <https://05-salon.vercel.app/>

## Ejecutar en local
```bash
cd 05_salon
npm install
npm run dev
```
Requiere Node.js 22 LTS (mínimo 20.19). Abrir la URL que muestra la terminal (normalmente http://localhost:5173).

## Login de prueba (simulado, sin base de datos)
Usuario `Admin` · Contraseña `1234` → habilita la ruta privada `/panelPrivado`.

## Estructura de `src`
- `componentes/` componentes reutilizables
- `paginas/` vistas de la aplicación
- `contexto/` autenticación simulada
- `estilos/` hojas de estilo
- `datos/` contenido de los servicios
- `multimedia/` imágenes, video y audio
